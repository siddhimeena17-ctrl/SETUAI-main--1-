# Website Images

This directory contains editorial images for the SetuAI website.

- `skypa-hero-classroom.png`: classroom concept imagery. It is not evidence of a SetuAI programme or partnership in itself.
- `skypa-ai-textbook.png`: textbook concept imagery. It is not evidence that the textbook has been published or distributed beyond the current reviewed materials.
- `skypa-partnership-workshop.png`: collaboration concept imagery. It is not evidence of a specific confirmed SetuAI partnership.
- `skypa-logo.png`: archived SKYPA Foundation partner logo. It must not be presented as the SetuAI logo.
- `skypa-higgsfield-heart.png`: archived SKYPA-branded concept image. It is retained for source history and must not be used as SetuAI brand artwork.
